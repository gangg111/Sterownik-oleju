Usterki · test zabezpieczeń

Restartów watchdoga: 0

Sklejony przekaźnik bezpieczeństwa wykrywa test przy każdym uruchomieniu pompy. Zwarty tranzystor: sterownik otwiera przekaźnik bezpieczeństwa i blokuje się. Zawieszenie: watchdog restartuje Arduino po 0,25 s, trzy z rzędu dają blokadę.
